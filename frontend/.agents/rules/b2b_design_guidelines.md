# Comprehensive B2B UI/UX Design Guidelines (ReuSource / Bylink Clean Eco Design)

Semua pengembangan antarmuka (UI) di workspace ini wajib mematuhi aturan berikut sesuai desain acuan ReuSource / Bylink:

## 1. Palet Warna & Tema
- **Background**: `#F6F9F5` / `#F8FAF8` (Clean Light Eco Mode)
- **Cards**: `#FFFFFF` dengan solid border `#E2E8F0`
- **Primary Green**: `#059669` / `#10B981`
- **Secondary Blue**: `#2563EB` / `#1D4ED8`
- **Dark Container**: `#0F172A` (Fitur Unggulan)

## 2. Tipografi
- **Headline**: `Plus Jakarta Sans` / `Inter`
- **Numbers**: `JetBrains Mono`
